# Timings on the full catalogue (Phase 19, S6)

Measured on 9 November 2026, after B13, when the catalogue held all 84
interests (252 places and 168 experiences, legacy ones included).

## Method

- Android emulator (1080 × 2400, 420 dpi) running the dev client against the
  production JS bundle (`npx expo start --dev-client --no-dev --minify`).
- Each action is timed from a screen recording with touch dots on
  (`show_touches`): the first frame where the touch dot appears, then the
  first frame where the target region changes ("first") and the frame after
  which it no longer changes ("settle"). Median of three runs.
- The emulator was restarted before the final runs: after 21 hours of
  uptime its graphics service sat at full load and a first set of runs gave
  numbers that said more about the host than the app. Those runs are not
  used below.

## Results

| Action                                            | First (median) | Settle (median) | Runs (settle)    |
| ------------------------------------------------- | -------------- | --------------- | ---------------- |
| Filtre: tap → sheet with "Vis N resultater"       | ≤ 1 frame      | 0.23 s          | 0.07, 0.23, 0.24 |
| Sveip, first visit after a cold start: tap → card | 0.30 s         | 0.46 s          | 0.43, 0.55, 0.46 |
| Mode switch, For deg → Live: tap → pins           | 0.12 s         | 0.12 s          | 0.13, 0.07, 0.12 |
| Welcome, "Fortsett som gjest" → map with tab bar  | 0 s            | 1.2 s           | 1.18, 3.00, 0    |

The welcome screen's photo moves, so the last row is noisy; its spread
(0 to 3 s) is wider than the others.

## Compared with earlier phases

- Filtre took about 10 s to open in the dev build before 0319 and 5.6 s
  after it (Kategori rows mount on first open). In production on the full
  catalogue it settles in about a quarter of a second, within its 320 ms
  slide.
- The first Sveip visit took 0.5–1.7 s to settle in Phase 10 (14 places, 6
  experiences); with the full catalogue it settles in about half a second,
  since the deck builds nearest first and loads only the cards it shows.

## Outcome

No action above half a second except the first map after the welcome
screen, which includes building the catalogue and mounting the native map.
No code was changed in this slice. iOS and real phones were not measured.
