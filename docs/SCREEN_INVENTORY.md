## Corrections to the 2026-11-05 text-only audit

The text-only audit (no pixels) flagged several items the PDF actually shows.
These are **not** mismatches:

- Guest mode ("Fortsett som gjest", map banner "Du utforsker som gjest") — p1, p5.
- Welcome copy "Oppdag nabolagets lune møteplasser" — p1 (keep).
- Map search groups "PÅ KARTET / GRUPPER / NYLIGE SØK" — p5 (app matches).
- Experience create ends in **"Publiser opplevelsen"** ("Publiseres umiddelbart ·
  chat opprettes automatisk") — p12. Only **places** go to review
  ("Send inn til vurdering", "Steder gjennomgås manuelt") — p11.
- Creator progression **"Veien til Skaper"** / "Bli Skaper" (3 requirements) — p12, p14.
- Swipe right = heart; then "Bli med i samtalen" sheet — p7, p8.
